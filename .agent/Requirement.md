# Requirement.md - Wenxi Cloud Disk

## 项目概述

**项目名称**: 文希云盘 (Wenxi Cloud Disk)

**项目类型**: 现代化云盘系统

**核心定位**: 客户端直连蓝奏云存储，服务器仅管理元数据的轻量级云盘

---

## 核心需求

### 1. 系统架构

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 客户端直连蓝奏云 | 文件上传/下载直接与蓝奏云交互 | P0 |
| 服务器元数据管理 | 仅存储文件信息、用户信息、加密密钥 | P0 |
| 节省带宽成本 | 服务器不中转文件流量 | P0 |
| E2E加密 | 客户端加密，服务器无法查看文件内容 | P1 |

### 2. 用户系统

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 用户注册 | 邮箱+密码注册 | P0 |
| 用户登录 | JWT Token认证 | P0 |
| 用户信息管理 | 查看/更新个人信息 | P1 |
| 会话管理 | Token过期/刷新 | P1 |

### 3. 文件管理

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 文件列表 | 按文件夹展示文件 | P0 |
| 文件上传 | multipart上传到服务器(暂定) | P0 |
| 文件删除 | 删除文件元数据 | P0 |
| 文件重命名 | 修改文件名 | P1 |
| 文件移动 | 移动到不同文件夹 | P1 |
| 文件夹管理 | 创建/删除/重命名/移动文件夹 | P0 |
| 批量操作 | 批量上传/删除/移动 | P2 |

### 4. 蓝奏云集成

| 需求 | 描述 | 优先级 |
|------|------|--------|
| Token管理 | 存储用户的蓝奏云Cookie/Token | P1 |
| 直链获取 | 获取文件直链用于下载 | P1 |
| 文件夹同步 | 同步蓝奏云文件夹结构 | P2 |

### 5. 分享功能

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 生成分享链接 | 创建公开分享链接 | P1 |
| 密码保护 | 分享链接密码保护 | P1 |
| 过期时间 | 分享链接过期设置 | P2 |
| 分享管理 | 查看/删除已创建的分享 | P1 |

### 6. 安全需求

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 零知识架构 | 服务器不存储文件内容 | P0 |
| E2E加密 | ChaCha20-Poly1305客户端加密 | P1 |
| 密钥分离 | 主密钥与文件密钥分离 | P1 |
| XSS防护 | 输入过滤,输出转义 | P0 |
| CSRF防护 | CSRF Token验证 | P0 |
| SQL注入防护 | 参数化查询 (GORM) | P0 |

## 技术约束

### 后端约束

- Go 1.21+
- Gin Web Framework
- GORM (但使用原生SQL，modernc.org/sqlite)
- 纯Go SQLite驱动 (无CGO)
- 无外部依赖部署

### 前端约束

- Vue 3.4+
- Vite 5+
- Tailwind CSS 4+ (无配置文件)
- Naive UI 2.x
- 浏览器: Chrome 90+, Firefox 90+, Safari 15+

### 部署约束

- 单服务器部署
- SQLite文件存储
- 无Redis/Memcached缓存
- 反向代理: Nginx (可选)
