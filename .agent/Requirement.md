# Requirement.md - Wenxi Cloud Disk

## 项目需求规范

### 核心需求

#### 1. 跨平台云盘系统
- **架构**: 客户端直连蓝奏云存储，服务器管理元数据
- **技术**: Go + Gin 后端，Vue 3 前端
- **目标**: 节省带宽成本，保留 E2E 加密

#### 2. 用户系统
- 用户注册/登录
- JWT 认证
- 用户信息管理

#### 3. 文件管理
- 文件元数据存储（名称、大小、蓝奏云 ID、加密密钥）
- 文件列表/详情/删除
- 批量操作支持

#### 4. 蓝奏云集成
- Cookie/Token 管理
- 客户端直连上传/下载
- 文件夹管理

#### 5. 分享功能
- 生成分享链接
- 密码保护
- 过期时间设置

#### 6. 安全需求
- 零知识架构：服务器无法访问用户文件内容
- E2E 加密：ChaCha20-Poly1305 客户端加密
- 密钥管理：主密钥 + 文件密钥分离

## UI 需求规范

### 视觉风格

#### 颜色系统
```css
--color-primary: #00D4FF;       /* 霓虹青 */
--color-background: #0A0E17;    /* 深空黑 */

```

#### 无圆角设计
- 全局 border-radius: 0px
- 卡片/按钮/输入框全部直角矩形
- 阴影: 锐利无模糊 (4px 4px 0px)

#### 字体规范
- 主字体: Inter, -apple-system, sans-serif
- 代码字体: JetBrains Mono, Consolas, monospace

## 性能指标

- API 响应时间 < 200ms
- 数据库查询 < 50ms
- JWT 验证 < 10ms
- 服务器内存占用 < 100MB
- 数据库连接池 < 10 连接
